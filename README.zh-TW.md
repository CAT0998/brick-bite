# 磚砌咬合 Brick Bite

## 1. 它解決什麼問題

FDM 列印件在 Z 方向最弱：同一位置逐層堆疊的牆，層與層之間的接縫完全對齊，受力時沿接縫開裂。

業界已知的緩解思路叫 **「磚砌層 / 交錯牆（Brick Layers / Staggered Perimeters）」**：讓相鄰層的牆在水平方向錯開，像砌磚一樣互相咬合。

**Brick Bite 的做法不同：一行幾何關係解決全部問題。**

---

## 2. 核心原理

設模型邊界為 `B`，外牆線寬 `w₀`，內牆線寬 `w₁`。

```
第 0 圈（外牆）：中心線 = B − w₀/2            ← 外表面始終貼在 B
第 1 圈（內牆）：中心線 = B − (2·w₀ + w₁)/2
```

隔層把 `w₀` 換成 `0.5·w₀` 之後：

- 外牆中心線內移 `w₀/4`，外表面仍然齊平；
- 第 1 圈中心線變為 `B − (w₀ + w₁)/2`，整體橫移 `w₀/2`；
- 於是相鄰兩層的牆縫正好錯開半個線寬。

**不需要多邊形偏移、不需要額外掃描線，只改那一圈的擠出寬度。**

### 兩種模式

| 模式 | 效果 |
|---|---|
| Half（0.5w ↔ w） | 奇數層外牆 0.5×，偶數層 1× |
| Wide（0.5w ↔ 1.5w） | 奇數層 0.5×，偶數層 1.5× |

設定位置：**工藝 → 強度 → 牆 → Brick wall mode**

## 3. 安裝

1. 到 [GitHub Release](https://github.com/CAT0998/brick-bite/releases) 下載安裝程式 zip；
2. 解壓後雙擊安裝程式，選擇你的 OrcaSlicer / Bambu Studio 目錄；
3. 原檔案會備份為 `*.brickbite.bak`，支援一鍵還原。

安裝程式支援 **簡體中文 / 繁體中文 / English**，自動辨識系統語言，也可在介面中手動切換。
