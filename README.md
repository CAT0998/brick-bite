## 1. 它解决什么问题

FDM 打印件在 Z 方向最弱：同一位置逐层堆叠的墙，层与层之间的接缝完全对齐，受力时沿接缝开裂。

业界已知的缓解思路叫 **“砖砌层 / 交错墙（Brick Layers / Staggered Perimeters）”**：让相邻层的墙在水平方向错开，像砌砖一样互相咬合。

现有实现大多靠：

- 对整圈墙做几何偏移（Clipper offset）——会改变轮廓、在圆环/孔洞结构中产生空隙；
- 在 G-code 里改路径——拿不到“第几圈、哪层”的语义，容易产生接缝；
- 隔层额外加一圈墙——增加材料与时间，且不是真正的错位。

**Brick Bite 的做法不同：一行几何关系解决全部问题。**

## 2. 核心原理

设模型边界为 `B`，外墙线宽 `w₀`，内墙线宽 `w₁`。

OrcaSlicer 生成墙时，各圈位置为：

```
第 0 圈（外墙）：中心线 = B − w₀/2            ← 外表面始终贴在 B
第 1 圈（内墙）：中心线 = B − (2·w₀ + w₁)/2
第 2 圈及以后：  再按 perimeter_spacing 依次内缩
```

由此得到一个关键关系：

$$
\text{内墙整组位置} = B - \frac{2w_0 + w_1}{2}
$$

**只改变首圈（外墙）的线宽 `w₀`，就会让第 1 圈及之后的所有内墙整体平移：**

$$
\Delta_{\text{内墙}} = \frac{\Delta w_0}{2}
$$

而且因为外墙中心线始终在 `B − w₀/2`，**外表面永远齐平**，不会凸出或凹陷。

同时，相邻两圈的间距恰好等于两者半宽之和：

```
间距(0→1) = (w₀ + w₁)/2 = w₀/2 + w₁/2
```

所以**不会产生重叠，也不会产生空隙**。

### 两种模式

| 模式 | 外墙线宽（奇数层 ↔ 偶数层） | 相邻层内墙位移 |
|---|---|---|
| 无 | — | 0 |
| 半宽交替 | 0.5w ↔ w | 0.5w（0.45 线宽时为 0.225 mm） |
| 宽窄交替 | 0.5w ↔ 1.5w | 1.0w（0.45 线宽时为 0.45 mm） |

## 3. 与已有方案的区别

| 方案 | 是否改几何 | 是否加路径 | 圆环/孔洞 | 外表面 |
|---|---|---|---|---|
| Bricklayers / 交错 perimeter | 是（offset） | 否 | 易空隙 | 需额外补偿 |
| 交替额外内墙 | 否 | 是（多一圈） | 好 | 不变 |
| G-code 后处理 | 是（改坐标） | 否 | 接缝难处理 | 易错 |
| **Brick Bite（本算法）** | **否** | **否** | **好** | **天然齐平** |

公开资料中未见“只改首圈线宽、让整组内墙平移”的同类实现，因此我们将其作为独立思路公开，用作**防御性发表（defensive publication）**。

## 4. 快速开始

### 4.1 应用补丁

补丁基于 OrcaSlicer 的 `staggered-perimeters-rebased` 分支（PR #8181 作者分支）：

```bash
git clone https://github.com/vipulrajan/OrcaSlicer -b staggered-perimeters-rebased
cd OrcaSlicer
git apply /path/to/brick_bite.patch
```

### 4.2 编译（Windows）

参考 `docs/BUILD.md`：VS 2022 Build Tools + CMake + Strawberry Perl，
依赖下载若被墙可把 URL 前缀改为 `https://ghproxy.net/https://github.com/`。

### 4.3 使用

编译后在 工艺 → 强度 → 墙 里：

```
砖砌咬合：首圈半宽交替 (Brick bite)
  ├─ 无
  ├─ 半宽交替（0.5w ↔ w）
  └─ 宽窄交替（0.5w ↔ 1.5w）
```

建议先用「半宽交替」验证效果，再试「宽窄交替」。

## 5. 已知限制

1. **表面条纹**：外墙线宽逐层变化，外表面会呈现宽窄交替的纹理，属预期现象；
2. **外墙同时变化**：外轮廓与孔洞的外墙共用同一 flow，会同时变宽/变窄（方向一致，不会错乱）；
3. **挤出稳定性**：0.5w（0.45 线宽时 0.225）偏窄、1.5w 偏宽，实际打印可能需要微调流量/压力提前；
4. **Arachne 变量宽度**：薄壁、悬垂场景本身线宽可变，叠加后效果需实测；
5. 仅验证过 PLA/PETG 常规参数，其它材料请自行测试。
